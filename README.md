# ride-nippy-website
RIDE NIPPY PRIVATE LIMITED — SIX-PAGE STATIC WEBSITE

Included pages:
1. index.html — Home
2. about.html — About Us
3. products.html — Our Products (7 categories)
4. product-details.html — Category/product details template (reads ?category= from URL)
5. business-enquiry.html — Wholesale, bulk, retailer and distributor enquiry
6. contact.html — Contact form and company contact placeholders

Shared assets:
- style.css — homepage/global styling
- pages.css — inner-page styling
- script.js — mobile navigation, current year, category selection, enquiry form behavior

Important before publishing:
- Replace the RN text mark with the approved company logo.
- Replace stock photography with genuine product/company photos when available.
- Add verified company address, phone, WhatsApp and email.
- In script.js replace ADD-COMPANY-EMAIL-HERE with the verified company email. Until then, forms do not send/store submissions.
- Add confirmed product varieties, ingredients, pack sizes, pricing, MOQ, nutritional details and certifications. None have been invented.
- Test all pages on desktop and mobile.

GitHub Pages:
Upload all files and folders to the root of your GitHub repository. Keep index.html at the repository root. Enable Pages in repository Settings > Pages and deploy from the main branch/root.
